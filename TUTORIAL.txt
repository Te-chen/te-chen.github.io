一、這是什麼？
──────────────────────────────────────────────────────────────────────

  這是一個極簡的個人網站，部署在 GitHub Pages：
    https://te-chen.github.io

  整個網站只有 1 個 HTML 檔案 + 1 個 CDN 載入的 Live2D 人偶。
  沒有框架、沒有建置步驟、沒有 node_modules。
  總體積不到 2 KB（HTML 本身），人偶資源從 CDN 按需載入。


二、從另一台電腦取得網站程式碼
──────────────────────────────────────────────────────────────────────

    git clone https://github.com/Te-chen/te-chen.github.io.git
    cd te-chen.github.io

  就這麼簡單。不需要 npm install，不需要任何環境。


三、檔案結構
──────────────────────────────────────────────────────────────────────

    te-chen.github.io/
    ├── index.html      ← 網站的全部內容
    ├── .gitignore      ← git 忽略規則
    └── .git/           ← git 倉庫資料

  只有一個檔案需要編輯：index.html


四、如何本地預覽
──────────────────────────────────────────────────────────────────────

  直接用瀏覽器打開 index.html 即可：
    - Windows：雙擊 index.html
    - Mac：open index.html

  不需要啟動任何伺服器。Live2D 人偶會直接從 CDN 載入。
  （需要網路連線才能看到人偶）


五、如何更換 Live2D 人偶
──────────────────────────────────────────────────────────────────────

  打開 index.html，找到這一行（約第 46 行）：

    jsonPath: 'https://cdn.jsdelivr.net/npm/live2d-widget-model-haru@1.0.5/01/assets/haru01.model.json'

  把網址中的 01 改成 02 即可切換到另一個 haru 造型：
    → 01 = blog 形象（當前使用）
    → 02 = root 形象（備選）

  如果要換成完全不同的角色（例如 miku），改成：
    https://cdn.jsdelivr.net/npm/live2d-widget-model-miku@1.0.5/assets/miku.model.json

  更多可用模型見同目錄下的 live2d-widget-report.txt 第五章。


六、如何修改頁面內容
──────────────────────────────────────────────────────────────────────

  編輯 index.html：
    - 標題：改 <title> 和 <h1> 標籤內的文字
    - 內文：在 <main> 區塊內加入任意 HTML
    - 樣式：修改 <style> 區塊內的 CSS

  範例 — 加入一段自我介紹：

    <main>
      <h1>Te-chen's Site</h1>
      <p>chat · cat · Katze</p>
      <p>這裡是新加入的文字。</p>       ← 新增這行
    </main>


七、如何部署（把修改發布到網站）
──────────────────────────────────────────────────────────────────────

    git add index.html
    git commit -m "描述你改了什麼"
    git push origin gh-pages

  推送後等待約 1-2 分鐘，GitHub Pages 會自動更新。
  然後到 https://te-chen.github.io 確認修改已生效。

  注意：分支名稱是 gh-pages，不是 main 或 master。
        如果 git push 失敗，先 git pull 拉取遠端更新再 push。


八、關於這個倉庫的說明
──────────────────────────────────────────────────────────────────────

  這個倉庫（te-chen.github.io）原本是一個 Hexo + Next 主題的部落格，
  後來因為內容極少且維護成本過高，在 2026-07-03 被簡化為單一 HTML 頁面。

  原本有兩個倉庫：
    - te-chen.github.io（根目錄站點）→ 保留並簡化為當前狀態
    - blog（子目錄站點 /blog/）→ 已刪除

  現在只有這一個倉庫，一個頁面，一個 Live2D 人偶。


九、常見問題
──────────────────────────────────────────────────────────────────────

  Q: 人偶沒顯示？
  A: 檢查：1) 有網路連線嗎？人偶從 CDN 載入
         2) 瀏覽器 Console 有沒有報錯（按 F12 查看）

  Q: 想在手機上看到人偶？
  A: 已經設定 mobile.show = true，手機上會自動顯示（較小尺寸）

  Q: 想恢復舊的部落格文章？
  A: 舊文章的備份在 git 歷史中。執行：
      git log --oneline
      git checkout <舊commit> -- <檔案路徑>
    可取出特定檔案。Markdown 原文備份也在 E:\02 根目錄的相關報告中。

  Q: CDN 掛了怎麼辦？
  A: jsdelivr 是免費 CDN，可靠性很高。如果真掛了，可以改用 unpkg：
     把 cdn.jsdelivr.net/npm 換成 unpkg.com
     （詳見 live2d-widget-report.txt 第三章）

  Q: 如何完全離線使用（不依賴 CDN）？
  A: 見 live2d-widget-report.txt 第七章方式二。需下載約 900KB 模型檔案。
